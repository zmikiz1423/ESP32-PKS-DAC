ESP32 Music Player

ติดตั้งหรืออัปเดตเฟิร์มแวร์เข้าสู่บอร์ด ESP32 ของคุณโดยตรงผ่านเบราว์เซอร์

⚠️ เบราว์เซอร์ของคุณไม่รองรับ Web Serial กรุณาเปิดด้วย Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์
คำแนะนำการใช้งาน:
1. เสียบสาย USB เชื่อมต่อบอร์ด ESP32 เข้ากับคอมพิวเตอร์
2. กดปุ่มด้านบน แล้วเลือกพอร์ต COM ของบอร์ด
3. หากหน้าจอค้างที่ "Connecting..." ให้กดปุ่ม BOOT ค้างไว้บนบอร์ดจนกว่าจะเริ่มดาวน์โหลด
